# discourse-deadlock

A minimal Discourse theme inspired by the visual language of Deadlock's “Old Gods, New Blood” page.

## Features

- Dark charcoal/bone/orange color scheme
- Oracle/Pulp-style remote font references from the public Deadlock CDN
- Grainy, poster-like body background effects
- Larger, bold headings with restrained topic-list styling
- Transparent table/list borders and minimal layout changes

## Local development

Import as a Discourse theme from this directory. The theme is intentionally CSS-only and uses Discourse variables where possible.
